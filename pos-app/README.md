# บันทึกรายรับรายจ่าย — Next.js + Supabase + Vercel

ร้านเดียว (single shop): ทุกคนที่ล็อกอินได้ เห็นและแก้ข้อมูลชุดเดียวกัน

## สิ่งที่มีในเวอร์ชันนี้
- ล็อกอิน (Supabase Auth) — เข้าได้เฉพาะคนที่ร้านสร้างบัญชีไว้
- หน้าแรก: เงินคงเหลือ (เงินเข้า − เงินออก), เงินเข้า/ออก/กำไรขั้นต้นเดือนนี้, กราฟ 7 วัน, ปุ่มขายสินค้า
- สินค้า: เพิ่ม/แก้ไข, ตัวเลือกสี/ไซส์, รูปสินค้า (Supabase Storage), เก็บเข้าคลังแทนการลบถ้ามีประวัติ
- ขายสินค้า: ค้นหา, เลือกจำนวน, คิดเงินทอน, กันขายเกินสต๊อกที่ฐานข้อมูล
- คลัง: รับสินค้าเข้า, ปรับยอด/ของเสีย (ห้ามติดลบ), "ต้องซื้ออะไรบ้าง", ประวัติ ก่อน → หลัง, ยกเลิกการรับเข้า
- ธุรกรรม: รายการทั้งหมด, ยกเลิกการขาย (คืนสต๊อก เก็บประวัติเดิม)

## ที่ยังไม่ได้ย้ายมาจากไฟล์ HTML เดิม
ตะกร้าหลายรายการ, ชุดขายซ้ำ, รายการโปรด, หน้าวิเคราะห์, งบประมาณ/สินทรัพย์/โน้ต, เครื่องคิดเลข, ธีม/โหมดมืด,
Backup/Restore, และ **การนำข้อมูลเก่าจากไฟล์ HTML เข้ามา** (ตารางสำหรับงบประมาณ/สินทรัพย์/โน้ต/ชุดขายซ้ำ/รายการโปรดมีใน schema แล้ว แต่ยังไม่มีหน้าจอ)

## ขั้นตอนติดตั้ง (ทำครั้งเดียว)

### 1) สร้าง Supabase project
1. ไปที่ https://supabase.com → New project (ตั้งรหัสผ่านฐานข้อมูล เลือก region ใกล้ไทย เช่น Singapore)
2. เมนู **SQL Editor** → New query → วางเนื้อหาไฟล์ `supabase/schema.sql` ทั้งหมด → **Run**
   (สร้างตาราง, สิทธิ์, bucket รูปสินค้า และฟังก์ชันขาย/รับเข้า/ปรับยอด/ยกเลิก)
3. เมนู **Authentication → Users → Add user** → ใส่อีเมล+รหัสผ่านของร้าน (ติ๊ก Auto Confirm)
4. เมนู **Authentication → Sign In / Providers** → ปิด "Allow new users to sign up" เพื่อไม่ให้คนอื่นสมัครเอง
5. เมนู **Project Settings → API** → คัดลอก `Project URL` และ `anon public key`

### 2) รันในเครื่อง (ถ้าต้องการลองก่อน)
```bash
npm install
cp .env.local.example .env.local   # ใส่ URL และ anon key
npm run dev                         # เปิด http://localhost:3000
```

### 3) Deploy บน Vercel
1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub (repo ใหม่)
2. https://vercel.com → Add New → Project → เลือก repo นั้น (Framework: Next.js ตรวจจับอัตโนมัติ)
3. ใน Environment Variables ใส่ 2 ตัว:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
4. กด Deploy
5. กลับไป Supabase → **Authentication → URL Configuration** → ใส่ Site URL เป็นโดเมน Vercel ของคุณ

## ข้อควรรู้
- `anon key` เป็นคีย์สาธารณะโดยออกแบบ ความปลอดภัยมาจาก Row Level Security + ล็อกอิน ห้ามเอา `service_role` key ไปใส่ในโปรเจกต์นี้
- รูปสินค้าถูกย่อก่อนอัปโหลด (Vercel จำกัดขนาดคำขอ ~4.5MB)
- สต๊อกเปลี่ยนได้ผ่านฟังก์ชันในฐานข้อมูลเท่านั้น (ขาย / รับเข้า / ปรับยอด / ยกเลิก) ไม่มีช่องแก้ตัวเลขสต๊อกตรงๆ
